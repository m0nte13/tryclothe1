# MONTE — установка на iPhone и публикация на GitHub Pages

## Публикация

1. Распакуйте архив `MONTE-iOS-PWA.zip`.
2. Откройте папку `monte_site`.
3. Загрузите **содержимое** этой папки в ту же папку GitHub-репозитория, из которой GitHub Pages публикует сайт (обычно корень репозитория или `/docs`).
4. Подтвердите замену старых файлов и дождитесь завершения GitHub Pages deployment.
5. Убедитесь, что файл `.nojekyll` тоже загружен в корень публикации.
6. Проверьте, что по адресам `https://ВАШ-ДОМЕН/manifest.webmanifest` и `https://ВАШ-ДОМЕН/sw.js` открываются манифест и JavaScript service worker.

Не загружайте папку `monte_site` внутрь старой папки сайта, если сейчас `index.html` находится в корне публикации: загружать нужно именно её содержимое.

## Установка на iPhone

1. Откройте опубликованный сайт в **Safari** (не во встроенном браузере Telegram/Instagram).
2. Нажмите кнопку «Поделиться» — квадрат со стрелкой вверх.
3. Прокрутите меню и выберите «На экран Домой» (при необходимости — «Изменить действия» и добавьте этот пункт).
4. Оставьте имя `MONTE` и нажмите «Добавить».
5. На домашнем экране появится иконка MONTE. Открывайте сайт через неё.

На iOS установка PWA выполняется через меню Safari «Поделиться» → «На экран Домой»; отдельная кнопка установки на странице не требуется.

## Что включено

- `manifest.webmanifest` — название, иконки, стартовая страница и режим standalone.
- `sw.js` — service worker и кэш оболочки для повторного открытия при нестабильном интернете.
- Иконки PNG для iOS и браузеров (в корне).
- Метаданные iOS добавлены в `index.html` и `tryon.html`.

Камера виртуальной примерки требует HTTPS и разрешения Safari. Офлайн-кэш не гарантирует работу камеры или внешних библиотек распознавания без интернета.
