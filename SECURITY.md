# Безопасность сайта MONTE

Сайт состоит из статических страниц:

- `index.html` — магазин;
- `checkout.html` — оформление и оплата;
- `tryon.html` — примерка через камеру.

Сервера нет: корзина и заказ живут в браузере, оплата работает в демо-режиме.
Ниже описано, что защищено сейчас и что нужно сделать перед запуском настоящего магазина.

---

## 1. Что было найдено и исправлено

| # | Проблема | Риск | Исправление |
|---|---|---|---|
| 1 | `checkout.html` принимал состав заказа из адреса (`#order=…`), а количество товара вставлялось в страницу без экранирования | **Высокий.** Можно было прислать покупателю ссылку, которая выполнит чужой код на странице оплаты (XSS) или подменит товары и цены | Чтение заказа из адреса убрано. Заказ передаётся только через хранилище браузера, а каждое поле проверяется |
| 2 | Корзина из `localStorage` загружалась без проверки | Средний | Из корзины отбрасывается всё, что не совпадает с каталогом |
| 3 | Ни на одной странице не было Content-Security-Policy | Средний | На все страницы добавлен CSP |
| 4 | Tailwind загружался с CDN без версии | Средний | Tailwind 3.4.17 скачан в `vendor/` |
| 5 | MediaPipe загружался при каждом открытии примерки | Низкий | Загрузка стала ленивой |
| 6 | Браузер мог восстановить данные карты | Средний | Поля карты очищаются |

## 2. Content-Security-Policy

Политика задана тегом `<meta http-equiv="Content-Security-Policy">`.

**Почему разрешён `'unsafe-inline'` для скриптов.** Код страниц написан прямо внутри HTML. Главная защита от XSS — экранирование при выводе и проверка входных данных.

## 3. Данные покупателя

- Сайт ничего не отправляет: ни контакты, ни адрес, ни данные карты.
- Данные карты проверяются только в браузере и стираются.
- Камера в примерке работает только локально.

## 4. Перед запуском настоящего магазина

1. Оплата только через платёжного провайдера.
2. Цены считает сервер.
3. Промокоды — только на сервере.
4. Персональные данные по 152-ФЗ.
5. Защита формы заказа на сервере.

## 5. Как проверить

- DevTools → Console: нарушения CSP видны как `Refused to load…`.
- [securityheaders.com](https://securityheaders.com) после публикации.
